Where do I type this?
  • Chat — open chat and type it with the leading /.
  • Command block — place a command block, tap it, paste without typing / (the block adds it).
  • Cheats must be on — most commands need cheats enabled in your world settings.
  • Chain tip — use needsRedstone off for always-on repeating blocks.
