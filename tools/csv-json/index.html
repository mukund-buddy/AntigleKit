Questions

        
CSV ↔ JSON FAQ

      

      

        

          Does the CSV parser handle quoted fields?
          
Yes — a field wrapped in double quotes can contain commas and even newlines. Two consecutive quotes inside become a single literal quote. That is exactly how real spreadsheet exports behave.

        

        

          Can the site see what I convert?
          
No. The conversion is pure local JavaScript. Nothing is uploaded, so sensitive rows and lists never leave the tab.

        

        

          What output does JSON → CSV produce?
          
An array of objects becomes one header row followed by one line per object. Primitive values and single objects also work; choose semicolon or tab as the delimiter for locale-friendly files.
