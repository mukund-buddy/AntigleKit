Install in Minecraft

  1. If the file arrives as .zip, rename it to .mcpack (turn on file name extensions in File Explorer's View menu), then double-click it — Minecraft opens and imports it automatically.
  2. Open Settings, go to Global Resources, and Activate the pack.
  3. Restart the game. Your photo now fills the title screen.

This pack modifies Minecraft's UI (JSON UI) and adds no behavior pack, so achievements stay enabled. If a specific Minecraft version restricts custom UI, the background may not appear — tell us the version and it can be adjusted.

How it works

From photo to pack, locally

Pick your screen ratio

Auto reads your device's screen and matches its aspect ratio, so the background fills the whole display. Prefer a fixed target? Choose 16:9, 16:10, 2:1, 19.5:9, or 4:3.

Frame the crop

The crop box is ratio-locked and centred. Drag it, use the slider or mouse wheel, and only the area inside the box is exported at your chosen resolution.

Download the .mcpack

The tool builds a valid Bedrock manifest, a pack icon, the background texture, and a JSON UI tweak, then zips them into a single importable pack — all in your browser.

Questions

MC Title Studio FAQ

Will this disable Minecraft achievements?

No. The pack only ships resource files — a manifest, a pack icon, a background texture, and a JSON UI tweak. It adds no behavior pack, so achievements stay enabled.

Which image should I use?

Use a landscape photo at least as large as your screen resolution, with the main subject near the centre. Menu buttons sit on top of the background, so a slightly soft or darker photo keeps the text readable. The crop box is ratio-locked and centre-aligned by default.

Does it work on phones and tablets?

Yes. The tool detects your screen's aspect ratio automatically and exports an image that overscans the screen by 120px, so notches and safe-area padding cannot leave black bars on any display.

Is my photo uploaded anywhere?

No. Cropping, PNG encoding, and the .mcpack assembly all run locally in your browser. Your image never leaves your device.

Why does the background not show on some versions?

Custom UI JSON is version-sensitive. The pack targets the standard start screen used by recent Bedrock releases. If your version restricts custom UI, the background may not appear — share your version number and it can be adjusted.
