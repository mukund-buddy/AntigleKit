Minecraft also writes a level.dat_old next to it — the previous save. It opens in this editor too, and it is the first thing to try if the current file will not load.

Safety

Editing safely

  • Stop the server or close the game first. Minecraft rewrites level.dat on autosave and on shutdown, and a running server will overwrite your edit — or worse, write over a half-copied file.
  • Keep the original. This editor never modifies the file you dropped in; it produces a new download. Keep the old copy until the world has loaded once.
  • Do not change tag types. Changing Difficulty from Byte to Int, or renaming a tag Minecraft expects, is how a world stops loading. Edit values, not the structure, unless you know why.
  • Keep the Bedrock header intact. The 8-byte header carries the storage version and payload length. The editor rewrites the length automatically and preserves the version; hand-edited files that lose it will not load.
Questions

Questions & answers

Can I edit level.dat without downloading software?

Yes — that is what this page is. The parser runs in your browser, so there is nothing to install and no operating system requirement beyond a current browser.

Why does my world still show the old name?

Because the name in the world list comes from LevelName inside level.dat, not from the folder name. Copying or renaming a folder leaves the tag untouched. Edit the tag and the list updates.

Does this work with level.dat_old?

Yes. level.dat_old is the previous save in the same format. If the current file is corrupt, open the _old copy, confirm it looks sane, and restore it under the original name.

Can I change the world seed here?

You can edit the seed tag, but it only affects terrain generated after the change — chunks already on disk keep the shape they were generated with, so the join between old and new terrain will be visible.

Will editing level.dat corrupt my world?

Corruption comes from editing while the server is running, or from changing tag types and names rather than values. Stop the server, edit values, keep a backup until the world has loaded once.
