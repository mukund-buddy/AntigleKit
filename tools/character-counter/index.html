Questions

        
Character counter FAQ

      

      

        

          Do spaces count as characters?
          
Both totals are shown: with spaces and without. SMS is billed by characters including spaces, so the "with spaces" total is the one that matters there.

        

        

          How long can a tweet be?
          
Posts show 280 characters in most cases. This tool flags whether your text fits that cap.

        

        

          What is a character vs a word?
          
A character is one typed symbol; a word is a whitespace-separated group of them. Essays use word limits; bios, titles, and SMS use character limits — so this tool measures characters.
