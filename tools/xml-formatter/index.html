How it works

        
Well-formed, well-spaced

      


      

        

          

            
Validate before you format

            
Every document is tokenised and checked for balanced tags, valid names, quoted attributes, comments and self-closing elements before any output is produced.

          

        

        

          

            
Precise error positions

            
Problems point to the exact line and column — no more eyeballing a wall of XML to find the missing closing tag.

          

        

        

          

            
Two output shapes

            
Format indents with two spaces and keeps text nodes intact; minify drops comments and whitespace-only nodes for transport. Both are readable, copyable and printable.

          

        

      

    

  


  
  

    

      

        
Questions

        
XML formatter FAQ

      

      

        

          Does it validate before formatting?
          
Yes. Tags, attributes, comments, CDATA and the declaration are validated first. A mismatched or unterminated tag reports the exact line and column instead of formatting garbage.

        

        

          What does minify remove?
          
Comments and whitespace-only text nodes are removed; the XML declaration, CDATA, DOCTYPE and attribute values are preserved so the meaning is unchanged.

        

        

          Is my XML uploaded?
          
No. Everything runs locally in your browser. Your documents never leave the tab.
